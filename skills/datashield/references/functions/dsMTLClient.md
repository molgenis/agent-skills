Server call: assign

```r
ds.setMyServerData(myServerKey, data, symbol)
```

- `myServerKey`: The identify of the access. myServerKey$server contained a valid server connection.
- `data`: The name of the target matrix on the server
- `symbol`: The name of the new variable

## ds.solveINMF

Solver of Federated integrative NMF. Solver of Federated NMF

Server call: assign + aggregate

```r
ds.solveINMF(
  datasources,
  Xs,
  newH,
  rank = 2,
  lam = 1,
  Sp = 1,
  opts = list(maxIter = 40, tol = 0.01, ter = 2),
  nDigits = 10
)
```

- `datasources`: The connections of servers
- `Xs`: The data matrices of multiple cohorts
- `newH`: The starting point shared component matrix H
- `rank`: The hyper-parameter indicate the number of latent variables
- `lam`: The hyper-parameter associated with L2 term
- `Sp`: The hyper-parameter controlling the sparsity
- `opts`: Options controlling the optimization procedure
- `nDigits`: The number of digits rounded for each number prepared for network transmission
