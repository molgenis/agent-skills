## ds.binary.helper

Function to create dummy variables from factor variables. This is a function to assist in converting several multi-level factor variables into dummy or binary variables

```r
ds.binary.helper(
  dataframe = NULL,
  factor_variables,
  newobj = NULL,
  datasources = NULL
)
```

- `dataframe`: the name of the dataframe that will be used to generate a synthetic dataset. Required.
- `factor_variables`: a vector of multi level factor variable names to be converted to binary
- `newobj`: character string, the name of the new dataframe to be created that holds the binaries.
- `datasources`: a list of DSConnection-class objects obtained after login to DataSHIELD - should be a single server

## ds.genCorFlex.helper

Function to generate synthetic data from private data on server using the package simstudy.. This is a function to generate synthetic data from private data on server. The function returns this synthetic data which can be used by the analyst to perform testing of code, visualization of data (on analyst computer) and testing of harmonization code.

```r
ds.genCorFlex.helper(
  dataframe = NULL,
  cont_variables,
  factor_variables,
  num_rows = 10000,
  datasources = NULL
)
```

- `dataframe`: the name of the dataframe that will be used to generate a synthetic dataset. Required.
- `cont_variables`: a list of continuous variables.
- `factor_variables`: a list of factor variables. Multi level factors must be converted into binaries (a limitation of simstudy).
- `num_rows`: number of rows of synthetic data to be generated. Default is 10000.
- `datasources`: a list of DSConnection-class objects obtained after login to DataSHIELD.

## ds.syn

Synthetic dataset generation. This function is similar to R function syn from the synthpop package.

Server call: aggregate

```r
ds.syn(
  data = NULL,
  method = "cart",
  m = 1,
  k = NULL,
  proper = FALSE,
  seed = "sample",
  datasources = NULL
)
```

- `data`: a string that is the name of a dataframe containing the variables to be included in the synthetic dataset
- `method`: a single string or a vector of strings of length ncol(data) specifying the synthesising method to be used for each variable in the data. Order of variables is exactly the same as in data.
- `m`: number of synthetic copies of the original (observed) data to be generated. The default is m = 1.
- `k`: number of rows of data to be generated
- `proper`: a logical value with default set to FALSE. If TRUE proper synthesis is conducted.
- `seed`: an integer to be used as an argument for the set.seed(). If no integer is provided, the default "sample" will generate one and it will be stored.
- `datasources`: a list of DSConnection-class objects obtained after login. If the datasources argument is not specified the default set of connections will be used: see datashield.connections_default.
