# DataSHIELD quick start
This page gives you a quick demonstration of DataSHIELD, from the perspective of a data manager or as a researcher.

## Data manager
As a data manager you will be using either Armadillo or Opal - the two server-side implementations of DataSHIELD. You can find a quick-start guide for Armadillo [here)](https://molgenis.github.io/molgenis-service-armadillo/), and documentation on Opal [here](https://opaldoc.obiba.org/en/latest/).

## Researcher
The wiki contains [detailed documentation](/en/getting-started/researcher) elsewhere on how to use DataSHIELD as a researcher. Here we have a small self-contained guide to try out DataSHIELD using the simulated [CNSIM dataset](/en/analysis-tutorials/data-available/cnsim).

### Install R studio
To run DataSHIELD you first need to [install R Studio)](https://posit.co/downloads/).

### Install and load dependencies

## View available data
First we can view the remote data available. We see there is a dataset in each server named 'cnsim'
```r
ds.ls()
```
We can inspect the column names of that dataset:
```r
ds.colnames("cnsim")
```
We can also fetch descriptive statistics, for example for BMI: 

```r
ds.summary("cnsim$PM_BMI_CATEGORICAL")
```

Next we can run a linear regression model, modelling how BMI is predicted by glucose levels, adjusting for sex

```r
output <- ds.glmSLMA(
  formula = "PM_BMI_CONTINUOUS~1+LAB_GLUC_ADJUSTED+GENDER", 
  dataName = "cnsim", 
  family = "gaussian"
)
```
We can view the coefficients for each cohort:
```r
output$betamatrix.valid
```
And the pooled coefficients via meta-analysis:
```r
output$SLMA.pooled.ests.matrix
```
Finally, we can make a forest plot showing the associations of glucose levels with BMI:

```r
ds.forestplot(output)
```

We end the session by logging out:
```r
datashield.logout(conns)
```
