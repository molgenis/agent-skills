# Viewing remote objects

To view the objects currently assigned in your remote workspace:
```r
ds.ls()
```

# Viewing object properties

## Class of an object
```r
ds.class("cnsim")
```
## Column names of a data frame
```r
ds.colnames("cnsim")
```

## Dimensions of a data frame or matrix
```r
ds.dim("cnsim")
```

## Length of a vector
```r
ds.length("cnsim$GENDER")
```
## Levels of a categorical variable
```r
ds.levels("cnsim$DIS_CVA")
```
