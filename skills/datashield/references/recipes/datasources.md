# Introduction
DataSHIELD is a platform primarily used to analyse data from multiple datasources. When you initially [log in](https://wiki.datashield.org/en/analysis-tutorials/logging-in-tutorials), you specify which datasources you want to access. All these datasources are then available for analyis, and as a default DataSHIELD functions will use all datasources.

# Specify which datasources to use.
However, there maybe times you only want to run a function for some of the available datasources. To control which datasources are used, you use the `datasources` argument. For example, if you only want to use the datasources named 'server1', you can specify this by adding the name of the datasource you want to use in square brackets:

```r
ds.ls(datasources = conns["server1"])
```
You can also specify to remove a datasource using `!`:
```r
ds.ls(datasources = conns[names(conns) != "server1"])
```
If you want to specify multiple datasources, use the `%in%` operator.
```r
ds.ls(datasources = conns[names(conns) %in% c("server1", "server2")])
```
In this case it is only for illustration, as we only have two datasources and are selecting them all. Using all datasources is the default:
```r
ds.ls()
```
