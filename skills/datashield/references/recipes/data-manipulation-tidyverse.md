# Introduction
This tutorial demonstrates how to perform data manipulation using the [``dsTidyverse``](https://github.com/molgenis/ds-tidyverse) and [``dsTidyverseClient``](https://github.com/molgenis/ds-tidyverse-client) packages. These are community packages which implement selected functions from the [``tidyverse``](https://www.tidyverse.org/) collection of R packages. To learn about all the functionality available you can view the vignette provided with these packages.

# Rename variables 🟢
`ds.rename` renames columns within a server-side data frame. Column names are passed unquoted to `tidy_expr` and are evaluated as column names within `df.name`.

``` {r}
ds.colnames("titanic")
```

```r
ds.rename(
  df.name = "titanic", 
  tidy_expr = list(person_name = Name, person_class = Pclass), 
  newobj = "new_df")

ds.colnames("new_df")
```

# Remove columns from a dataframe
`ds.select` creates a subset of columns in a server-side data frame. Column names are passed unquoted to `tidy_expr` and are evaluated as column names within `df.name`.

### Keep columns by name
```r
ds.select(
  df.name = "titanic", 
  tidy_expr = list(Sex, Age, Survived), 
  newobj = "titanic_2")

ds.colnames("titanic_2")
```

### Keep a range of columns
``` {r}
ds.select(
  df.name = "titanic", 
  tidy_expr = list(Sex:Cabin), 
  newobj = "titanic_3")

ds.colnames("titanic_3")
```

### Remove columns by name
``` {r}
ds.select(
  df.name = "titanic", 
  tidy_expr = list(!SibSp), 
  newobj = "titanic_4")

ds.colnames("titanic_4")
```

# Subset a data frame by rows
Subset set a data frame flexibly, retaining all rows that satisfy the condition supplied to `tidy_expr`

```r
ds.dim("titanic")
```

```r
ds.filter(
  df.name = "titanic",
  tidy_expr = list(Survived == 1 & Sex == "female"),
  newobj = "titanic_5",
  datasources = conns)

ds.dim("titanic_5")
```

# Create new variables within a data frame
`ds.mutate` creates new columns in a server-side dataframe. These new columns are normally transformations of existing columns. Again, column names are passed unquoted to `tidy_expr` and are evaluated as column names within `df.name`.

```r
ds.mutate(
  df.name = "titanic",
  tidy_expr = list(age_months = Age*12),
  newobj = "titanic_6")

ds.mean("titanic_6$age_months")$Mean.by.Study
```

# Transform a variable based on one condition
`ds.if_else` allows you to specify a condition, and return values based on whether the condition is 'true' or 'false'
```r
ds.if_else(
  condition = list(titanic$Age > 18),
  "Adult",
  "Child",
  newobj = "titanic_7")
ds.table("titanic_7")$output.list$TABLE_rvar.by.study_counts
```

# Transform a variable based on multiple conditions
An extension of `ds.if_else` which allows the specification of multiple conditions. Extremely
useful for recoding variables.

```r
ds.case_when(
  tidy_expr = list(
    titanic$Fare < 20 ~ "low",
    titanic$Fare >= 20 & titanic$Fare < 40 ~ "medium",
    titanic$Fare >= 40 ~ "high"),
  newobj = "titanic_8")

ds.table("titanic_8")$output.list$TABLE_rvar.by.study_counts
```

# Combine data frames by row
Bind any number of data frames by row, making a longer result. This is similar to do.call(rbind, dfs), but the output will contain all columns that appear in any of the inputs.

```r
ds.dim("titanic")
```

```r
ds.bind_rows(
  to_combine = list(titanic, titanic),
  newobj = "titanic_9"
)

ds.dim("titanic_9")
```

# Combine data frames by column
Bind any number of data frames by column, making a wider result. This is similar to do.call(cbind, dfs).

First create some copies with selected columns:
```r
ds.select(
  df.name = "titanic", 
  tidy_expr = list(Survived, Pclass), 
  newobj = "titanic_sub_1")

ds.colnames("titanic_sub_1")
```

```r
ds.select(
  df.name = "titanic", 
  tidy_expr = list(Parch, Ticket), 
  newobj = "titanic_sub_2")

ds.colnames("titanic_sub_2")
```

Now join these together:

```r
ds.bind_cols(
  to_combine = list(titanic_sub_1, titanic_sub_2),
  newobj = "titanic_sub_3"
)
ds.colnames("titanic_sub_3")
```

# Sort a data frame
`arrange` is a more flexible version of `base::sort`, which orders the rows of a data frame by the values of selected columns.
```r
ds.arrange(
  df.name = "titanic",
  tidy_expr = list(Sex),
  newobj = "arranged_df"
  )
```
